## What ASTER does — manufacturer information

ASTER is multiseat software that enables **multiple independent workspaces from a single physical host**. Individual users can work with separate displays, keyboards and mice while sharing host resources. The vendor describes a product configuration of **up to 12 workplaces** for standard product/licensing presentation. Actual capacity depends on CPU, graphics, RAM, display outputs, peripherals, applications and license type.

The vendor emphasizes a software-based deployment without requiring separate thin-client hardware for each seat. Users can have independent desktop sessions; hardware capacity, application licensing and per-application multiuser restrictions still matter.

### Published product capabilities

- Multiple workplace layouts on one PC; assign monitors and input devices.
- Support for multiple graphics outputs and vendor-described peripheral sharing/assignment.
- Windows desktop and supported Windows Server environments, plus a separate Linux edition.
- Trial evaluation before purchasing; **14-day fully functional Windows trial** on the vendor site.
- Standard license types aligned to workplace count; the **PRO-USB** hardware-key option supports offline licensing under vendor terms.
- Vendor documents setup, peripheral considerations, troubleshooting and licensing.

## Local VWEB.DEV implementation scope (self-described)

1. **Assess:** review number of users, application workloads, CPU, memory, GPU outputs, display count, peripheral needs, and OS/build.
2. **Plan:** determine workspace layout, software/licensing option and any physical devices/adapters.
3. **Trial:** validate all intended workplaces against actual applications and peripherals.
4. **Deploy:** install, configure user devices and verify session independence.
5. **Handover:** document activation, hardware/driver changes, operator controls and support routes.
6. **Support:** troubleshoot workstation assignment, licensing and Windows compatibility issues under agreed service scope.

Use cases described by the partner: school labs, offices, call centers and shared workstation environments. Gaming workloads demand special GPU/resource planning and cannot be promised universal compatibility.

## Licensing

The Pakistan site presents workplace-based annual, lifetime Pro and USB-Pro routes. Prices and promotion terms can change; VWEB.DEV's commercial materials say to confirm current Pakistan prices, taxes, hardware costs and installation/support scope before ordering.

**Important:** software licensing and vendor/product support should be checked alongside any Windows, Windows Server, game/application or device licenses. Running multiple workspaces does not grant extra third-party license rights.
