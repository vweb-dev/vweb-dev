## Distinguishing types of evidence

- **Public portfolio:** [vweb.dev](https://vweb.dev/) and [portfolio directory](https://vweb.dev/portfolio).
- **Public source code:** [vweb-dev repositories](https://github.com/vweb-dev?tab=repositories); only public repositories should be linked.
- **Private project work:** do not publish source code, internal roadmaps, credentials, contracts, private metrics or unapproved client artifacts in this profile repository.

## Good case-study framework

**Business context → problem → design/technical scope → measurable change (only when verified) → operational handover.**

Before adding performance figures, confirm the exact measurement window, baseline, methodology and permission to disclose.
